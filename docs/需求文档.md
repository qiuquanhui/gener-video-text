# 闪电下载 · 万能视频下载网站 — 需求文档

> 版本：v1.0 ｜ 更新日期：2026-10-12 ｜ 状态：阶段 1-3 开发中
> 本文档是产品需求的权威来源，供团队开发与**后续 AI 辅助扩展功能时提供上下文**。修改需求请同步更新本文档并记录变更。

## 1. 项目背景与目标

### 1.1 背景
很多同学有下载保存视频到本地的需求，但各视频平台存在限制：
- 部分平台不提供下载功能
- 不支持批量下载、限制下载次数
- 下载清晰度受限、操作不便
- 手机端难以保存视频到本地

### 1.2 产品目标
做一个**万能视频下载网站**，让用户能够：
- 更快速地、随时随地、从各个平台下载视频
- 手机浏览器直接用，无需安装 App
- 额外提供视频文本提取、AI 视频总结等增值能力

### 1.3 设计原则（已确认的决策）
| 决策点 | 结论 | 说明 |
|---|---|---|
| 前端风格 | 吸引人、突出实用价值 | 复刻参考站 `https://ai.codefather.cn/painting` 的蓝白 SaaS 风格 |
| 后端 | 轻量，无数据库 | 任务与状态存内存，文件落盘临时目录定期清理 |
| 下载引擎 | 站在巨人肩膀上 | 直接封装 yt-dlp 开源项目（子进程调用，零修改源码） |
| 免费策略 | **全站核心功能免费不限量** | 下载不限次数/不限清晰度/无需登录，文本提取同样免费 |
| 付费点 | **AI 视频总结为会员专属** | 模拟支付 + 激活码解锁；二期替换真实支付 |
| 文本提取实现 | yt-dlp 字幕能力 | 下载平台字幕/自动字幕转纯文本；Whisper 本地转写留二期 |
| 开发节奏 | 5 阶段串行 | 每阶段：开发→自主测试→用户验收→通过后进入下一阶段 |

## 2. 用户故事

1. 作为**学生**，我想把 B 站教程视频下载到本地离线观看，以便通勤路上学习。
2. 作为**内容创作者**，我想下载自己发布的视频做二次剪辑，平台客户端下载有水印/清晰度限制。
3. 作为**手机用户**，我在微信里刷到视频，想保存到相册/文件，但平台不让下载。
4. 作为**学习者**，我想把视频的字幕文本提取出来做笔记和资料整理。
5. 作为**忙碌的用户**，我想用 AI 一句话总结视频内容，快速判断是否值得完整观看（会员）。

## 3. 功能清单

### P0 — 核心业务（阶段 1-3 交付）
| # | 功能 | 说明 |
|---|---|---|
| 1 | 视频解析 | 粘贴链接 → 展示标题/封面/时长/作者/平台/可用清晰度（4K~360P、MP3 音频） |
| 2 | 视频下载 | 选清晰度 → 服务器下载（自动合并音视频为 mp4 / 提取 MP3）→ 用户保存文件 |
| 3 | 下载进度 | 实时百分比、速度、ETA、状态（下载中/合并中/转码中/完成/失败） |
| 4 | 文件保存 | 附件式下载，手机浏览器可直接保存；文件保留 2 小时后自动清理 |
| 5 | 文本提取 | 一键提取视频字幕/自动字幕为纯文本，可复制、下载 .txt（免费） |
| 6 | 前端单页应用 | 复刻参考站蓝白 SaaS 风格，PC/移动端自适应 |

### P1 — 增值与付费（阶段 4 交付）
| # | 功能 | 说明 |
|---|---|---|
| 7 | AI 视频总结 | **会员专属**。基于提取的文本生成 AI 总结；优先调 OpenAI 兼容 LLM API，未配 Key 时降级本地抽取式摘要 |
| 8 | 会员体系 | 模拟支付（微信/支付宝占位二维码）+ 激活码解锁；定价区展示免费版 vs 会员 |
| 9 | VIP 激活 | 激活码（config 内置，如 `VIP2026`）；localStorage token 标识会话 |

### P2 — 二期方向（本轮不做，扩展时参考）
- 批量下载（多链接队列）、播放列表下载
- 本地 Whisper 语音转写兜底（无字幕视频也能提取文本）
- Cookie 配置（支持 B 站 1080P+、会员内容等需登录资源）
- 字幕翻译、真实支付接入、用户账号体系
- 字幕时间轴保留（srt/vtt 直接下载）

## 4. 免费与付费边界（重要）

| 能力 | 免费用户 | 会员 |
|---|---|---|
| 视频下载（次数/清晰度） | ✅ 不限 | ✅ 不限 |
| MP3 音频提取 | ✅ | ✅ |
| 字幕文本提取 | ✅ | ✅ |
| AI 视频总结 | ❌ | ✅ |
| 未来新功能 | 按届时政策 | 优先体验 |

## 5. 非功能需求

- **轻量**：无数据库；单进程；内存管理任务；前端 Vue3 本地 vendor（运行时零外网依赖）
- **安全**：URL 仅允许 http(s) 且防子进程参数注入；子进程数组传参不走 shell；并发下载上限 3
- **隐私**：下载文件 2 小时后自动删除，不持久化用户数据
- **兼容**：主流移动/桌面浏览器；390px 宽度移动布局可用
- **部署**：本地开发 `python main.py` 一键启动（阶段 5 补充服务器/Docker 说明）

## 6. 已知限制与边界（如实告知用户）

1. 少数平台不支持（如小红书），解析时报友好错误
2. 需要登录的内容（如 B 站 1080P+ 部分）匿名只能拿到较低清晰度 —— Cookie 支持留二期
3. 无字幕/无自动字幕的视频无法提取文本 —— Whisper 兜底留二期
4. 未配 LLM API Key 时 AI 总结为本地抽取式摘要（页面明确标注），配 Key 后自动切换真 AI
5. 任务与文件存内存/临时目录，服务重启后进度丢失

## 7. 术语表

| 术语 | 含义 |
|---|---|
| 解析(parse) | 用 yt-dlp `-J` 获取视频元数据，不产生下载 |
| 清晰度(quality) | 用户可选择的档位：2160(4K)/1440(2K)/1080/720/480/360 或 mp3 |
| 任务(task) | 一次下载请求的状态单元（id/进度/文件路径等），仅存内存 |
| 文本提取 | 下载平台字幕/自动字幕并转为纯文本 |
| VIP/会员 | 通过模拟支付或激活码解锁 AI 总结等付费能力的会话状态 |
