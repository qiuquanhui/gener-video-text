## 1. 架构总览

```

└────────────────────────┬────────────────────────────────┘
```

## 2. 技术选型与决策记录（ADR 摘要）

| # | 决策 | 备选 | 理由 |
|---|---|---|---|
| 1 | yt-dlp 以**子进程**方式调用（`python -m yt_dlp`） | 直接 import yt_dlp Python API | 进程隔离（崩溃不影响服务）；CLI 参数稳定；输出易解析；完全零修改开源代码 |
| 2 | FastAPI + uvicorn | Flask / Node | 原生 async 子进程管理契合下载场景；自动 OpenAPI 文档 |
| 3 | 无数据库，内存任务表 | SQLite | 用户要求轻量；任务为短生命周期（≤2h）临时态 |
| 4 | Vue3 本地 vendor，无构建链 | Vite 工程 / 原生 JS | 用户选定 Vue3；本地 vendor 使运行时零外网依赖，单进程可部署 |
| 5 | 进度用**前端轮询**（800ms） | SSE/WebSocket | 实现最简、最稳；后续可平滑升级 SSE |
| 6 | 文本提取用 yt-dlp 字幕下载 | Whisper / 云 API | 用户确认；零额外依赖最轻量；Whisper 兜底留二期 |
| 7 | LLM 可插拔（config 配 Key 即启用） | 写死某家 API | OpenAI 兼容协议（GLM/DeepSeek/OpenAI 均兼容），未配 Key 降级本地抽取式摘要 |
| 8 | 项目独立 `.venv` | 系统 Python | 本机存在双 Python（3.10/3.11 PATH 错乱），隔离保证可复现；**需用 3.11+**（yt-dlp 已弃用 3.10 警告） |
| 9 | B 站防风控请求头（Chrome UA + Referer + 伪 buvid3 Cookie） | 默认 UA | 实测匿名高频请求触发风控（`No video formats found`）；加头后稳定（仅对 bilibili 域名生效，见 `downloader.browser_args()`） |
| 10 | 错误信息过滤 `Deprecated Feature` 等噪音 | 原样透出 stderr | 保证用户看到的是干净的友好错误 |

## 3. API 契约

所有 POST body 为 JSON。错误统一 `{"detail": "友好中文错误"}` + 4xx/5xx。

### 3.1 `GET /api/health`
`{"status": "ok"}`

### 3.2 `POST /api/parse` ｜ body `{"url": "https://..."}`
执行 `yt-dlp -J --no-playlist --no-warnings <url>`（超时 60s）。响应：
```json
{
  "title": "视频标题", "thumbnail": "封面URL", "duration": 213,
  "uploader": "UP主", "platform": "哔哩哔哩", "webpage_url": "...",
  "qualities": [
    {"value": "1080", "label": "1080P 高清", "type": "video", "filesize": 12345678, "filesize_label": "11.8 MB"},
    {"value": "mp3",  "label": "MP3 音频",  "type": "audio", "filesize": null, "filesize_label": null}
  ]
}
```
- 清晰度档位：2160(4K 超清)/1440(2K 超清)/1080/720/480/360，按视频实际可用高度归并去重
- 平台名从 `extractor_key` 映射常见中文（BiliBili→哔哩哔哩、DouYin→抖音…），未知则原样返回

### 3.3 `POST /api/download` ｜ body `{"url": "...", "quality": "1080"|"mp3"}`
→ `{"task_id": "...", "status": "downloading"}`（不限次数、不限清晰度）

### 3.4 `GET /api/tasks/{task_id}`（前端 800ms 轮询）
```json
{
  "status": "downloading|merging|converting|done|error|expired",
  "progress": 45.6, "speed": "2.3MiB/s", "eta": "00:12",
  "title": "...", "filename": "xxx.mp4",
  "download_url": "/api/file/xxx",   // 仅 done
  "error": "..."                     // 仅 error
}
```
状态机：`downloading → merging|converting → done`，任一步失败 → `error`；文件过期清理后查询 → `expired`。

### 3.5 `GET /api/file/{task_id}`
FileResponse 附件下载（Content-Disposition 带安全化文件名）。文件不存在 → 410 `文件已过期，请重新下载`。

### 3.6 `POST /api/extract-text` ｜ body `{"url": "..."}`
执行 `yt-dlp --skip-download --write-subs --write-auto-subs --sub-langs "zh.*,en" --sub-format "srt/vtt" -o downloads/subs/<uuid>/%(id)s.%(ext)s`（超时 90s）→ 解析 srt/vtt 为纯文本。响应：
```json
{"title": "...", "lang": "zh-Hans", "chars": 3512, "text": "..."}
```
无字幕 → 400 `"该视频没有可用的字幕..."`。

### 3.7 阶段 4 预留（本次不实现）
`POST /api/summarize`（会员校验：请求头 `X-Client-Token` + 激活态）、`POST /api/vip/activate` `{"code": "VIP2026"}`。

## 4. 核心流程

### 4.1 下载（含进度解析）
```
POST /api/download
 └─ 校验 URL（^https?:// 且不以 - 开头）→ 建任务 → 后台协程（Semaphore 并发上限 3）
     └─ 子进程：
        视频：yt-dlp -f "bv*[height<=H]+ba/b[height<=H]" --merge-output-format mp4
              --progress --newline --no-playlist -o downloads/%(id)s.%(ext)s
              --print after_move:filepath <url>
        音频：yt-dlp -f "ba/b" -x --audio-format mp3 --audio-quality 0 （其余同上）
     └─ 逐行读 stdout：
        [download] Destination: …   → 分片计数 +1（bv+ba 合并下载有两段）
        [download]  45.6% of 10MiB at 2MiB/s ETA 00:03 → 总进度=（分片-1+pct/100)/预计分片数
        [Merger]…/[ExtractAudio]…  → 状态 merging/converting，进度 99%
        裸路径行（--print 输出）     → 记录最终文件路径
     └─ 进程退出码 0 且文件存在 → done + download_url；否则 error（stderr 尾部做友好化）
```
进度行正则：`[download]\s+([\d.]+)%\s+of\s+~?\s*([\d.]+\w+)(?:\s+at\s+((?:[\d.]+\w+/s)|Unknown\s*B/s))?(?:\s+ETA\s+(?:Unknown|([\d:]+)))?`

### 4.2 字幕 → 纯文本（text_extractor.py）
1. 独立临时目录下载字幕（`zh.*,en` 通配可命中 `zh-Hans`、B 站 `ai-zh` 自动字幕）
2. 多语言文件优先 zh；解析：去序号/时间轴行（`-->`）/`WEBVTT` 头/`<...>` 标签/HTML 实体，**连续重复行去重**（自动字幕滚动重复）
3. 返回纯文本 + 字数；临时目录即删

1. **导航栏**：白底粘顶；⚡logo「闪电下载」；菜单：首页/功能/定价/常见问题；右侧「🔓 解锁会员」按钮

4. **功能特性**：4 列 × 2 行 = 8 卡片（秒级解析/超清画质/文本提取/全端适配/完全免费/海量平台/隐私安全/AI 总结）
5. **定价区**：免费卡（¥0）vs 会员卡（¥9.9/月，蓝色描边+「最受欢迎」角标+权益清单），会员 CTA 唤起模拟支付
6. **FAQ 手风琴**（6 条）+ **页脚**（链接+版权+免责声明）

## 7. 扩展指引（给后续 AI/开发者）

- **加新 API**：在 `backend/main.py` 加路由；业务逻辑放独立模块；错误抛 `BusinessError(msg)` 统一转 HTTP
- **Whisper 兜底**：在 `text_extractor.extract_text` 无字幕分支接入 faster-whisper（任务化复用 downloader 的 Task 进度框架）
- **Cookie 支持**：`config.py` 加 `COOKIE_FILE`，子进程命令统一加 `--cookies <file>`（建议在 downloader 的 `_base_args()` 汇总）
- **批量下载**：前端多行文本域 → 循环调 `/api/download`，复用现有任务与轮询
- **真实支付/账号**：引入数据库后，把内存 Task 表与 VIP 会话迁入；API 契约不变
- **SSE 进度**：新增 `GET /api/tasks/{id}/events`，轮询契约保留做降级
- **LLM 接入**：`config.py` 填 `LLM_BASE_URL/LLM_API_KEY/LLM_MODEL`（OpenAI 兼容），`summarizer.py` 已按此协议设计

## 8. 本地开发与运行

```bash
# 首次（Python 3.11+）
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt

# 启动（后端 + 前端静态托管，单进程）
.venv/Scripts/python.exe backend/main.py
# 访问 http://127.0.0.1:8000
```

依赖系统 `ffmpeg` 在 PATH（负责合并/MP3 转码，本机已装 8.1.2）。

## 9. 测试夹具说明

`tests/fixtures/` 提供字幕提取的集成测试环境：`test.html` 是带 HTML5 `<track>` 字幕的标准视频页（yt-dlp generic 提取器原生支持）。启动 `python -m http.server 8765`（在 fixtures 目录）后，将 `http://127.0.0.1:8765/test.html` 交给 `/api/extract-text` 即可端到端验证字幕解析（标签剥离/实体转换/连续去重）。真实平台方面：当前网络环境下 B 站字幕需登录 Cookie、境外平台不可达，属已知限制（见需求文档 §6）。
