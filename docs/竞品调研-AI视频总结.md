## 1. BibiGPT（bibigpt.co）详细分析

**产品形态**：粘贴链接/上传本地 mp3/mp4/srt → 约 30 秒出结构化总结。宣称累计服务 100 万+ 用户。

- **支持平台（20+）**：B 站、YouTube、小红书、抖音、TikTok、Twitter/X、播客（Apple/小宇宙/Spotify）、Coursera/TED、任意网页；另可上传本地文件
- **输出形态**：
  1. 带时间戳的结构化总结（摘要 + 章节划分）
  2. 全文转写（SRT/VTT/纯文本）
  3. 思维导图 / 大纲
  4. 内容改写：文章、PPT、小红书图文、推特
  5. 字幕翻译与压制；画面内容分析（视觉理解）
- **多端**：Web（中/国际站）、浏览器插件（Chrome/Firefox/Edge）、桌面端（Tauri）、移动端（Expo）、MCP/Agent 接口
- **生态联动**：一键推送 Notion、导出 Obsidian Markdown（保留时间戳/章节/链接结构）
- **定价**（[官方文档](https://docs.bibigpt.co)，2025-11 版，常有折扣）：
  | 方案 | 价格 | 说明 |
  |---|---|---|
  | 月度 Plus | ¥141.37/月（原价 ¥282.74） | 每月 6,000 credits 算力 |
  | 月度 Pro | ¥248.47/月（原价 ¥496.94） | 每月 6,000 credits，更高速率 |
  | 合伙人 | ¥6,340.32 一次性 | 永久 |

## 2. NoteGPT 哔哩哔哩摘要器（notegpt.io/cn/bilibili-summarizer）详细分析

**产品形态**：NoteGPT 学习工具矩阵（AI 笔记/闪卡/测验/PDF 总结/浏览器扩展）中的 B 站专项页，强调「原生理解中文字幕，而非 YouTube 工具的中文适配」。

- **核心输出**：宣称 10 秒生成带时间戳结构化摘要（每个要点可跳转原视频时间点，支持数小时长视频）、AI 思维导图、中文转录 + 多语言翻译（英/日/韩/法等）、导出文本/Markdown/PDF/Word
- **使用流程**：粘贴 B 站链接 → 生成 → 摘要/导图/转录三区展示 → 一键保存到「My Notes」工作区
- **与矩阵联动**：笔记工作区、AI 追问对话、闪卡/测验（页脚生态，联动深度未明示）
- **定价**：落地页宣称「真正免费、无需信用卡」；FAQ 与[新手指南](https://notegpt.io)口径为**免费版约 15 次 AI 配额**，用完升级付费（第三方对比页显示 $9.99/月：1,000 基本配额 + 100 高级积分；$29/月：无限基本 + 2,800 高级积分——**需以官网定价页为准**）。

## 3. 共性规律（行业标配功能集）

1. **输入即链接**：无需上传，粘贴 URL 是默认交互（我们已有）
2. **输出三层结构**：一句话摘要 → 带时间戳的章节要点 → 完整转录；思维导图高频出现
3. **时间戳是留存关键**：要点可跳转原视频，是从「看总结」回到「看视频」的钩子
4. **追问对话（Chat with video）** 已是标配第二层
5. **商业化统一为配额制**：免费少量额度引流（BibiGPT 注册送、NoteGPT 15 次）+ 订阅解锁
6. **登录几乎是硬门槛**（至少免费层需要登录）——与我们「免登录激活码」模式形成差异

## 4. 对本项目的启示

- **同链路优势**：竞品需自建"链接→字幕"管线，我们已具备（解析 + 字幕提取已完成）；AI 总结是在现有 `extract-text` 之上加一层 LLM 调用
- **MVP 输出建议对齐标配**：一句话摘要 + 章节化要点（含时间戳）+ 关键词；思维导图/追问/内容改写列为二期
- **差异化卖点**：免登录即可用（激活码即会员）、与下载/MP3/文本提取一站式打通、定价远低于竞品
- **重要技术约束**：带时间戳的章节总结要求**字幕时间轴**——当前 `text_extractor.py` 会剥离时间轴只留纯文本，若做时间戳要点需扩展保留时间信息（影响工作量，需决策）
- **现实边界**：B 站匿名拿不到字幕（需登录 Cookie）、抖音无字幕接口——当前 AI 总结可用的真实输入源有限，无字幕视频依赖二期 Whisper 转写

## 5. 待人工确认问题清单

1. **输出形态（MVP 范围）**：A. 纯文本卡（一句话摘要+要点+关键词，不改字幕管线）；B. 带时间戳章节要点（需扩展字幕管线保留时间轴）；是否需要思维导图？
2. **LLM 供应商**：config 预留了 OpenAI 兼容协议（GLM/DeepSeek/OpenAI 均可）——你有可用的 API Key 吗？用哪家？未配 Key 时按原方案降级「本地抽取式摘要」还是直接提示不可用？
3. **会员边界**：维持「AI 总结=会员专属 + 模拟支付/激活码」，还是参照竞品给免费用户少量体验额度（如每日 1 次）？
4. **结果导出**：弹窗展示 + 复制 + 下载 .md/.txt 是否足够？
5. **输入范围**：先支持「能提取到字幕的平台」（与现有 extract-text 同边界）即可？
