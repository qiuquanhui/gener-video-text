# 部署指南（Linux 服务器）

以 CentOS 8 为例（其他 RHEL 系/Debian 系同理，包管理器命令替换即可）。全程约 20 分钟。

> 原则：**任何密钥、服务器 IP/密码只存在于服务器与本地的 gitignored 文件中，绝不进入仓库**。

## 1. 环境准备

```bash
# CentOS 8 已 EOL，先把源切到 vault（CentOS 7/其他系统跳过）
sed -i -e 's|^mirrorlist=|#mirrorlist=|g' \
       -e 's|^#baseurl=http://mirror.centos.org|baseurl=http://vault.centos.org|g' \
       /etc/yum.repos.d/CentOS-*.repo

dnf -y install nginx tar xz
```

**Python 3.10+**（系统源自带的 3.6/3.8 不够，代码使用了 PEP 604 类型语法）：

```bash
# 方案 A（推荐，免编译）：Miniconda，国内用清华镜像
curl -fsSL -o /tmp/miniconda.sh https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash /tmp/miniconda.sh -b -p /opt/py312 && /opt/py312/bin/python -V
# 方案 B：源码编译 3.12（需先装 gcc openssl-devel libffi-devel zlib-devel bzip2-devel readline-devel sqlite-devel xz-devel）
```

**ffmpeg**（合并/MP3 转码必需；注意 EPEL 的 rpm 版可能因 mpg123/libopenmpt 版本错配启动报错，建议直接用官方静态包）：

```bash
# 本机下载后 scp 上服务器（服务器直连 GitHub 通常很慢）
curl -fsSL -o ffmpeg-static.tar.xz https://github.com/BtbN/FFmpeg-Builds/releases/latest/download/ffmpeg-master-latest-linux64-gpl.tar.xz
scp ffmpeg-static.tar.xz root@<服务器IP>:/tmp/
# 服务器上：
cd /tmp && tar xf ffmpeg-static.tar.xz
install -m 755 ffmpeg-master-latest-linux64-gpl/bin/ff* /usr/local/bin/
ffmpeg -version | head -1
```

## 2. 部署代码

```bash
# 本地打包（等价于已推送的 HEAD，天然不含 gitignored 文件）
git archive --format=tar.gz -o deploy.tar.gz HEAD
scp deploy.tar.gz backend/local_config.py root@<服务器IP>:/tmp/

# 服务器上
mkdir -p /opt/shandian && tar xzf /tmp/deploy.tar.gz -C /opt/shandian
mv /tmp/local_config.py /opt/shandian/backend/local_config.py && chmod 600 /opt/shandian/backend/local_config.py
mkdir -p /opt/shandian/data /opt/shandian/downloads
/opt/py312/bin/python -m venv /opt/shandian/venv
/opt/shandian/venv/bin/pip install -i https://mirrors.aliyun.com/pypi/simple/ -r /opt/shandian/requirements.txt
```

## 3. systemd 常驻

`/etc/systemd/system/shandian.service`：

```ini
[Unit]
Description=ShanDian video downloader (FastAPI)
After=network.target

[Service]
User=shandian
Group=shandian
WorkingDirectory=/opt/shandian
Environment=PUBLIC_BASE_URL=http://<你的域名或IP>
ExecStart=/opt/shandian/venv/bin/python backend/main.py
Restart=always
RestartSec=3
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

```bash
useradd -r -s /sbin/nologin -d /opt/shandian shandian
chown -R shandian:shandian /opt/shandian
systemctl daemon-reload && systemctl enable --now shandian
curl -s http://127.0.0.1:8000/api/health   # 应用自检
```

## 4. nginx 反代（80 → 127.0.0.1:8000）

`/etc/nginx/conf.d/shandian.conf`（**SSE 流式文章必须 `proxy_buffering off`**；若 nginx.conf 内联了默认 server 块需删除，避免 default_server 冲突）：

```nginx
server {
    listen 80 default_server;
    server_name _;
    client_max_body_size 10m;
    gzip on;
    gzip_types text/css application/javascript application/json image/svg+xml text/plain;
    gzip_min_length 1024;
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering off;      # SSE
        proxy_read_timeout 600s;  # AI 长任务
        proxy_send_timeout 600s;
    }
}
```

```bash
# SELinux 放行 nginx 回连本机端口（Enforcing 时必需）
getenforce | grep -qi enforcing && setsebool -P httpd_can_network_connect 1
systemctl enable --now nginx && nginx -t && systemctl restart nginx
# 云厂商安全组放行 80/443；firewalld 在跑则 firewall-cmd --permanent --add-service=http && firewall-cmd --reload
```

## 5. 验收清单

- `curl http://127.0.0.1/api/health` → `{"status":"ok"}`（经 nginx）
- 浏览器打开 `http://<IP>/` 首页正常、`/js/app.js` 200
- 注册→登录→`GET /api/auth/me` 返回 `logged_in:true`
- `POST /api/vip/activate {"code":"VIP2026"}` → **400 激活码无效**（演示码默认已下线；如需本地演示设环境变量 `VIP_CODES=VIP2026`）

## 6. 授予账号永久 VIP（管理员操作）

以运行用户执行一次性脚本（用完即删，勿入库）：

```python
import sys, time
sys.path.insert(0, "/opt/shandian/backend")
import auth_api, db
db.init_db()
EMAIL, PASSWORD = "user@example.com", "<初始密码>"
if not db.get_account_by_email(EMAIL):
    db.create_account(EMAIL, auth_api._hash_password(PASSWORD))
acct = db.get_account_by_email(EMAIL)
db.set_membership_expiry(acct["id"], 9992448000.0)   # 2286-01-01，事实永久
acct = db.get_account_by_email(EMAIL)
assert db.is_vip(acct) and auth_api._verify_password(PASSWORD, acct["password_hash"])
print("OK", acct["email"], acct["vip_expires_at"])
```

## 7. 已知生产限制

- **机房 IP 风控（已适配）**：B 站网页抓取对云服务器 IP 返回 412，本项目 B 站解析/字幕/下载已改走**纯 API 直连**（`bilibili_fp.py` 指纹 + `bilibili_video.py` view/playurl + urllib 拉流 + ffmpeg 本地合并）；抖音匿名凭证失败时走 ttwid 注册接口兜底。已在阿里云机房 IP 实测 B 站/抖音解析、字幕提取、视频/MP3 下载全链路可用。注意：**ffmpeg 静态版直接拉 B 站 CDN 会 I/O error（其 HTTP 栈兼容性问题），不要改回 ffmpeg 直连 URL 的方式**；若平台风控进一步收紧，可给 systemd 加 `Environment=HTTPS_PROXY=...` 住宅代理
- HTTP 明文：账号密码登录未加密，建议尽快绑域名 + HTTPS（证书后打开会话 Cookie `secure`，见 `docs/Stripe接入指南.md` 生产 Checklist）
- Stripe 未配置密钥时，开通会员入口显示配置指引，不影响其他功能
- 数据备份：定期备份 `/opt/shandian/data/app.db`（账号/订单/额度全在此文件）
